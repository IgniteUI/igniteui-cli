# React Data Binding

The Ignite UI for React map component is designed to display geo-spatial data from shape files and/or geographic locations from data models on geographic imagery maps. The `dataSource` property of geographic series is used for the purpose of binding to data models.

## Types of Data Sources
The following section list some of data source that you can bind in the geographic map component

- [Binding Data Models](./geo-map-binding-data-model.md)
