# Web Components Chart Title and Subtitle

The title and subtitle feature of the chart control allows you to add information to the top section of the Web Components charts.

## Example



## API References

When adding a title or subtitle to the chart control, the content of the chart automatically resizes allowing for the title and subtitle information.

| Property Name         | Property Type   |     Description  |
| ----------------------|------------------|------------|
| [`chartTitle`](mcp:get_api_reference?platform=webcomponents&component=IgcCategoryChartComponent&member=chartTitle)          | string |  Title's text content.  |

| [`titleAlignment`](mcp:get_api_reference?platform=webcomponents&component=IgcCategoryChartComponent&member=titleAlignment)      | HorizontalAlignment |  Title's horizontal alignment.  |
| [`titleTextStyle`](mcp:get_api_reference?platform=webcomponents&component=IgcCategoryChartComponent&member=titleTextStyle)      | string | Title's font style, e.g. Italic Bold 8pt Times New Roman  |
| [`titleTopMargin`](mcp:get_api_reference?platform=webcomponents&component=IgcCategoryChartComponent&member=titleTopMargin)      | number | Title's top margin.  |
