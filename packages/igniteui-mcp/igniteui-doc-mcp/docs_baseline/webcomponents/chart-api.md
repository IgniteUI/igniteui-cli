# Web Components Charts API

The Ignite UI for Web Components charts provide simple and easy to use APIs to plot your data in [`IgcCategoryChart`](mcp:get_api_reference?platform=webcomponents&component=IgcCategoryChartComponent), [`IgcFinancialChart`](mcp:get_api_reference?platform=webcomponents&component=IgcFinancialChartComponent), [`IgcDataChart`](mcp:get_api_reference?platform=webcomponents&component=IgcDataChartComponent), [`IgcDataPieChart`](mcp:get_api_reference?platform=webcomponents&component=IgcDataPieChartComponent), [`IgcDoughnutChart`](mcp:get_api_reference?platform=webcomponents&component=IgcDoughnutChartComponent), [`IgcPieChart`](mcp:get_api_reference?platform=webcomponents&component=IgcPieChartComponent), and [`IgcSparkline`](mcp:get_api_reference?platform=webcomponents&component=IgcSparklineComponent) UI elements.
