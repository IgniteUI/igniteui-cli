# Component Templates

Component templates are pre-configured Angular component scaffolds that the Ignite UI CLI (`ig add`) and Ignite UI Angular Schematics (`ng g @igniteui/angular-schematics:c`) generate into an existing Angular project. Each template produces a working Angular component with the correct imports, module declarations, and a sample dataset - ready to run without additional configuration. Templates are available for grids, charts, gauges, maps, layout components, menus, notifications, data entry controls, interactions, scheduling controls, and full application scenarios.

These templates generate components into an existing Angular workspace only. They do not create a new Angular project - use `ig new` or `ng new` for that. Templates are specific to Ignite UI for Angular; equivalent patterns for React, Web Components, and Blazor are covered in the respective framework documentation. The generated code serves as a functional starting point and may differ from the live demos linked in this page, which reflect the full documentation samples.
