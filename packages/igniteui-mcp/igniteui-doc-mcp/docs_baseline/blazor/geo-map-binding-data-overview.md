# Blazor Data Binding

The Ignite UI for Blazor map component is designed to display geo-spatial data from shape files and/or geographic locations from data models on geographic imagery maps. The [`DataSource`](mcp:get_api_reference?platform=blazor&component=IgbSeries&member=DataSource) property of geographic series is used for the purpose of binding to data models.
